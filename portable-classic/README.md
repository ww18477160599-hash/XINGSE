## 🌟 核心工作流与架构设计

### 1. 软件运行架构说明
- **绿色免安装桌面架构**：软件无需繁重安装流程，随拷随用。采用 **原生 Windows 桌面引导程序 (`形色.exe`)** + **本地轻量微服务 (`127.0.0.1:3721`)** + **独立沉浸式桌面视窗**。
- **独立专属启动图标**：内置定制的黑金光圈镜头高清图标 (`app.ico`)。
- **窗口关闭即随关后台**：**彻底解决后台常驻残留问题**！当您关闭「形色」应用视窗时，系统自动捕捉窗口退出信号，并**同步彻底结束后台 Node 服务进程**，退出干净无残留。
- **启动方式**：
  - **推荐方式 1**：直接双击运行根目录下的 **`形色.exe`**。
  - **推荐方式 2**：双击运行 **`创建桌面快捷方式.bat`**，即可一键在 Windows 桌面上生成带专属高清图标的「形色 XINGSE」快捷方式，双击桌面图标随时启动。
  - **传统脚本**：保留 `启动形色.bat` 与 `启动形色(无黑框).vbs` 备用；关闭亦可使用 `关闭形色.bat`。

## 💎 核心操作与形色逻辑

### 一、独立“核心锁定池”
1. **清楚可见的置顶池展示**：
   - 处于主控制台顶部最醒目区域，全景展示当前锁定的所有硬性条件。
   - 每项格式严格规范为：`[分组名·字段名＝值]`（例如 `上装·颜色＝酒红`、`下装·面料＝牛仔`、`创作·画幅＝16:10`）。
2. **入锁与解锁机制**：
   - 仅用户主动点击选项或添加自建选项时，才会进入锁定池；
   - 导演搭配或库内随机抽取的临时结果**绝不自动入锁**；
   - 支持单项点击 `✕` 移除锁定，或一键点击“全部解锁”。
3. **服装分区智能隔离**：
   - 依据 `outfit_mode`（服装组合形式）确定当前生效分区：
     - 上下装 / 成套装生效时：上装与下装生效，一体装停用；
     - 连衣裙 / 连体装生效时：一体装生效，上装与下装停用；
   - 停用分区中的字段在锁定池中保留原值并标注 `[当前不生效]`，不会发送给导演或生图模型；切回后无缝自动恢复。

### 二、提示词工作区与生图直读工作流
1. **宽敞舒适的审阅区域**：
   - 提供“收起/展开控制台”一键切换按钮，收起后提示词审阅区最大化撑满屏幕；
   - 首次打开界面时提示词框与锁定池均保持全空，不自动填入任何预设模板或虚构人物。
2. **单一提示词框直读生图**：
   - 全局仅设一个核心提示词编辑框 (`#main-prompt-box`)，不设隐藏提交窗口；
   - 导演搭配完成后将完整方案直接写入该框；
   - 用户在框内任意增删修改文字，生图提交完全以此框内的实时文字为准；
   - 框内为空或仅有空格时，“🚀 生图”按钮自动禁用。
3. **条件变更提示与工作流防护**：
   - 若提示词框内已有方案，此后修改选项或锁定，系统将弹出醒目的黄色提示条：“⚠️ 条件已变更，需要重新搭配”，绝不擅自覆盖已审阅的文字。

---

### 三、提示词操作按钮群
- **🎬 搭配**：以当前生效的锁定池为硬性铁律，由大模型摄影导演协调未锁定维度，生成完整提示词写入框中。只生成文字，不自动生图。
- **🚀 生图**：直接读取并提交提示词框内的当前完整文字给生图模型出图。
- **✨ 优化提示词**：在现有框内文字方案上优化，严格保留主角身份、锁定条件与核心设计，提升光影质感与物理连贯性。
- **🎲 库内随机**：保留用户已有锁定项，仅重抽未锁定的生效维度；抽取结果不自动加入锁定池。
- **📋 复制提示词**：一键复制完整提示词到剪贴板。

---

### 四、生图、尺寸与历史回溯
1. **画幅与分辨率精准映射**：
   - 支持 1:1 (1024×1024)、16:10 (1440×900)、16:9 (1344×768)、3:2 (1216×816)、4:3 (1152×864)、3:4 (864×1152)、2:3 (816×1216)、9:16 (768×1344) 等常用主流尺寸；
   - 在生图前及控制台中明确显示当前画幅对应的实际提交尺寸。
2. **本地保存与状态检测**：
   - 严格进行本地磁盘文件写入校验，实际写入成功后才标记“已保存”并显示本地路径；
   - 生成成功但写入失败时，明确提供“重试保存到本地”按钮。
3. **真实历史回溯**：
   - 保存作品标题、实际提交正文、模型参数、尺寸、锁定池及本地图片路径；
   - 点击“复原作品”直接恢复当时实际提交的完整提示词文字至提示词框，并还原当时的选项与锁定池。
4. **连通性测试 (零费用优先)**：
   - 支持通过查询 `/models` 进行无出图、零费用的接口握手检测；
   - 真实出图测试提供明确费用提醒。
